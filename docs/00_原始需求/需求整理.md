# 原始需求整理（来源：客户《流程(1).docx》与 7 个界面截图）

> 原始文件在项目根目录：`../流程(1).docx`、`../界面(1)/1.jpg ~ 7.jpg`、相机手册 `MV-CL043-A1GC_20241115.pdf`、算力盒手册 `TW-T201P用户指南.pdf`。
> 本文是对它们的整理，便于开发时查阅；有歧义以原始文件和客户确认为准。

## 1. 系统组成

| 部件 | 型号 / 说明 |
|---|---|
| 线阵相机 | 海康 MV-CL043-A1GC：4096 像素三线彩色线阵，GigE，RGB8 最高 9 kHz 行频（Bayer8 28 kHz），曝光 3 µs~10 ms，支持内/外触发（行触发、帧触发），M42 口 |
| 算力盒 | 图为 TW-T201P：Jetson Orin Nano 8G，Ubuntu + JetPack，2 网口（1G + 5G）、UART（/dev/ttyTHS1，3.3V TTL）、CAN、40 针 GPIO、M.2 NVMe |
| 下位机主控 | 控制喷阀（每台相机对应 64 个喷头）、输送带、给料机、清灰；指令格式"地址 + 指令"，**协议待定** |
| HMI | 7 个页面，由前端同事开发；与算力盒之间通过网口通讯 |
| 机型 | 皮带式；当前 1 路相机 |

文档措辞"部署到算力盒中 / 查询算力盒中的模型编号 / 像素值保存在算力盒中"表明 HMI 与算力盒是两台设备：**HMI ↔ 算力盒 ↔ 下位机**。

## 2. 七个界面与功能

### 2.1 开始页（1.jpg）
- 运行 / 暂停 / 停止：发给下位机主控的指令（地址 + 指令）。**开机默认直接运行分选程序**。
- 使用方案：显示当前模型；"调用方案"弹出模型列表，选择已训练模型 → 确认后部署到算力盒并保存。开机时查询算力盒中的当前模型编号并显示（或显示上次使用的模型）；没有方案时默认模型 1。
- 方案说明：可编辑并保存。
- 顶栏：保存（💾）、电源（关机/退出）；底栏：当前时间、总运行时长。

### 2.2 运行控制页（2.jpg）— 全部为发给下位机的参数/指令
| 项 | 范围 | 说明 |
|---|---|---|
| 开阀时间 | 0~255 | 单位待定 |
| 阀门维持 | 0~255 | 单位待定 |
| 阀门重吹 | 0~50 | 单位待定 |
| 延时 | 0~800 | 相机到喷阀的延时，单位待定（行数或 ms） |
| 孔位 | 0~768 | 喷阀检测用的喷头编号（768 = 12 × 64，推测最多 12 组） |
| 单阀检测 / 循环检测 / 复位 | — | 喷阀检测指令 |
| 清灰时间 / 清灰周期 / 清灰次数 | 0~200 / 0~200 / 0~5 | 加"清灰"使能复选框 |
| 输送 / 喷阀 / 给料 | 开关 | 手动开关三个执行机构 |

### 2.3 图像页（4.jpg）— 建模与样本管理（文档"一：新建模型 / 二：管理模型 / 三：采集设置"）
新建模型流程：
1. 点"新建模型"；
2. 选择要保存到的模型编号（系统文件中做好根目录和文件结构）；
3. 选择本次采样的样本类别（样本 A~G，共 7 类；文档中"样品D"重复一次系笔误）；
4. 选择采图使用的相机编号；
5. 点"连续采样"：采到的大图**自动裁切成一张一张小图**，存入第 2 步模型目录下第 3 步类别的文件夹；缩略图显示在小方框里，点缩略图可在大框预览，可**删除 / 撤销删除 / 全部删除（清空样本）**；可"追加样本"（自动开启连续采集）；
6. 换类别重复 3~5；
7. 点"标记为"下的样本 A~G 可查看该类当前样本与预览，并做删除/撤销/清空/追加；
8. 确认样品无误后点"开始训练"，训练好的模型自动保存在第 2 步的模型目录。

管理模型：
- 点"模型 1~7"按钮可查看该模型中的样本类别（有样本的类别按钮高亮），点高亮类别查看图片，可删除或追加；
- 点某个模型按钮时在其下方弹出操作框：**训练**（样本有改动则重新训练并生成新模型文件）、**删除模型**（删除所有参数和图片）、**备份至**（选择目标模型编号，连图片一起复制过去）。
- 打开该页面时默认显示主页正在使用的模型；**每次更改这个模型后会自动更新到主页并直接重新部署到算力盒**（除非编辑的不是当前使用的模型）。
- 页面内所有操作按钮点击时都要弹确认框（HMI 侧实现）。

采集设置：自动分割小图的参数，例如膨胀、腐蚀、过滤等，"根据软件编程需要自行定义内容"。

### 2.4 调整页（5.jpg）
- 吹气选择：下拉选择哪个样本类别需要吹气（可能多选，待确认）；

### 2.5 功能页（6.jpg）— 相机设置
- 相机号下拉 + 查询；自动白平衡（一次/连续/关）；曝光时间；图像宽度 4096；图像高度 4096；
- 起始像素 / 结束像素（0~4096）+ 下发：值保存在算力盒中；
- 连续采集 / 单次采集：预览；
- 显示：由于显示器限制，显示区分两段，前段显示 1~500 像素，后段显示 3597~4096 像素，中间丢掉不显示；图中白线是起始/结束像素的标尺，调节加减按钮时白线按像素移动并对齐刻度。
- "集合相机 SDK 做初始化操作"。

## 3. 像素 → 喷头映射规则（文档第四部分）

- 起始像素记作 A，结束像素记作 B（整数），相机对应喷头数 64；
- 有效像素 (B − A) ÷ 64 = 商 q … 余数 r；
- 文档用 64 行表格逐一列出 r = 0~63 时各喷头分到的像素数，归纳为一条规则：

> **前 ⌈r/2⌉ 个喷头各分 q+1 个像素，后 ⌊r/2⌋ 个喷头各分 q+1 个像素，中间喷头各分 q 个像素。**

校验示例（与原表一致）：r=1 → 1 号孔 q+1；r=2 → 1 号、64 号 q+1；r=3 → 1~2 号、64 号 q+1；r=4 → 1~2 号、63~64 号 q+1；r=63 → 1~32 号、34~64 号 q+1，33 号 q。

原始 64 行表已转成单元测试用例（见 `tests/test_nozzle.py`），实现必须逐行通过。
